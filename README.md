# Разряд

Разрядные нормативы ЕВСК по плаванию и очки разряда по времени заплыва.

**[razryad.borozdov.ru](https://razryad.borozdov.ru)**

## Что делает

Приложение стоит на одном адресе `/` и держит два режима одного экрана. Выбор бассейна, пола, стиля и дистанции общий и стоит выше режима, поэтому переключение меняет только панель под ним и ничего из выбранного не теряет.

1. **Нормативы.** Режим по умолчанию, тот, что показывает голый адрес: таблица девяти ступеней ЕВСК на выбранной дистанции.
2. **Калькулятор.** Второй режим, `?mode=calculator`. Введённое время даёт выполненный разряд, остаток секунд до следующей ступени и очки по шкале 0–1000, всё на одном экране без скролла.

Рядом лежит справочный слой из пререндеренных страниц: `/normativy/` с адресом на каждое из 35 событий датасета и `/razryady/` с разбором лестницы разрядов. Приложение ставится на домашний экран, работает без сети после первой загрузки и отдаёт результат карточкой в системный шеринг. Регистрации нет, аккаунтов нет, данные пользователя не хранятся.

Очки, это внутренняя метрика продукта, а не официальный статус. Разряд присваивает спортшкола или орган власти по протоколу старта нужного ранга.

## Очки

Шкала натягивает непрерывное число 0–1000 на дискретную сетку ЕВСК. Каждый разряд получает фиксированную отметку (`RANK_POINTS` в [scale.ts](src/domain/points/scale.ts)), между отметками результат считается по кубической зависимости, как в системе очков World Aquatics:

```
S = S1 + (S2 - S1) * ((T1/T)^3 - 1) / ((T1/T2)^3 - 1)
```

По оси `x = 1/T³` шкала линейна, поэтому вся кривая, это ломаная по узлам, а интерполяция, экстраполяция и сами узлы идут одним путём в коде. Выше самой быстрой ступени продолжается верхний отрезок. Ниже самой медленной ломаная идёт до неявного узла «бесконечное время, ноль очков», и очки остаются положительными на всей области.

Возраст фильтрует присвоение, а не расчёт: ступени, выполненные по времени, но недоступные по возрасту, уходят в `blockedByAge`.

## Данные

Числа берутся только из приложения № 1 к приказу Минспорта России от 06.11.2024 № 1092, [номер опубликования 0001202411150002](http://publication.pravo.gov.ru/document/0001202411150002). Сторонние сайты в датасет не попадают.

Датасет, это статические TS-модули, версионированные по редакциям: [editions/2024-11-26](src/domain/standards/editions/2024-11-26). Времена записаны так, как их печатает приказ, `m:ss.hh`, чтобы строку можно было сверить со сканом не переводя её в голове. 70 строк, 35 событий, два бассейна.

Zod-схема и контрактный тест `dataset.test.ts` держат форму: ключ `pool|sex|stroke|distance` уникален, времена строго убывают по ступеням, прочерк приказа выражен отсутствием ключа, а не нулём, покрыто ожидаемое множество событий для обоих бассейнов.

## Стек

| Слой | Выбор |
|---|---|
| Язык | TypeScript 5, `strict: true` |
| Фреймворк | Next.js 15, App Router, `output: 'export'` |
| Пакетный менеджер | pnpm |
| Слой данных | статические TS-модули в репозитории |
| Валидация датасета | Zod, только в тестах |
| Стили | CSS Modules плюс глобальные CSS-переменные ролей |
| Тесты | Vitest, fast-check |
| CI | GitHub Actions |
| Хостинг | Timeweb Cloud, статический экспорт |

Серверного рантайма нет. Всё, что его требует, запрещено: серверные экшены, роут-хендлеры, ISR, middleware, оптимизатор изображений, динамический роут без `generateStaticParams`.

## Разработка

```bash
pnpm install
pnpm dev
```

Четыре проверки, те же, что CI гоняет на каждый PR:

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

`pnpm build` пишет готовый сайт в `out/`. Чтобы посмотреть на него как на статику, раздайте этот каталог любым сервером.

## Структура

```
src/
  app/        роуты: страница только собирает данные и рендерит компонент
  domain/     чистая логика: шкала очков, время, датасет и доступ к нему
  features/   представление фич: приложение, калькулятор, справочный слой, PWA, шеринг
  ui/         примитивы: не знают о предметной области и не импортируют из domain/
  lib/        адреса, подписи, метаданные, тексты, тема
public/       манифест, иконки, сервис-воркер, стартовые экраны
```

Цветовых значений вне `globals.css` не существует, в модулях только `var(--role)`. Числа рендерятся моноширинным шрифтом с `font-variant-numeric: tabular-nums`. `any` запрещён, включая `as any`.

## Деплой

Timeweb Cloud собирает приложение из `main` и раздаёт `out/`. Автодеплой на пуш, сборка идёт на их раннере (`pnpm build`), потому что `out/` в `.gitignore`.
