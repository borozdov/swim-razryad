# РАЗРЯД

Разрядные нормативы ЕВСК по плаванию и очки FINA по времени заплыва. Статический сайт, ставится на домашний экран, после первой загрузки работает без сети.

**[razryad.borozdov.ru](https://razryad.borozdov.ru)**

## Что делает

Две функции стоят на одном адресе `/` двумя режимами одного экрана. Выбор бассейна, пола, стиля и дистанции общий и стоит выше режима, поэтому переключение меняет только панель под ним и ничего из выбранного не теряет.

**Нормативы.** Режим по умолчанию, тот, что показывает голый адрес. Таблица выбранной дистанции: девять ступеней ЕВСК, оба пола рядом.

**Калькулятор.** Режим `?mode=calculator`. Введённое время даёт выполненный разряд, остаток секунд до следующей ступени и очки FINA, всё на одном экране без скролла.

Регистрации нет, аккаунтов нет, данные пользователя не хранятся. Расчёт целиком в браузере.

## Очки

Очки, это очки FINA, они же World Aquatics Points, и считаются так же, как в [fina.borozdov.ru](https://fina.borozdov.ru): одно время в двух приложениях даёт одно число. Для времени `T` и базового времени события `B`:

```
P = floor(1000 · (B/T)³)
```

Базовое время, это мировой рекорд на дату начала действия таблицы World Aquatics, на нём ровно 1000. Таблица 2026 года лежит в `src/domain/points/baseTimes.ts` со ссылкой на официальный PDF. У бассейнов разные сроки: 25 м обновляется 1 сентября, 50 м 1 января, и тест краснеет, когда таблица вышла из срока.

Разряды стоят на той же шкале узлами: у ступени столько очков, сколько даёт её собственный норматив. На проверочной строке, мужчины, 50 м вольным, бассейн 50 м, I спортивный `25.20` даёт 571, КМС `23.95` даёт 665.

Возраст на числа нормативов не влияет, он решает только то, какую ступень можно присвоить: МСМК с 14 лет, МС с 12, КМС с 10, взрослые разряды с 9, юношеские с 8. Выполненное по времени, но закрытое возрастом уходит отдельным полем `blockedByAge`.

Очки, это не официальный статус. Разряд присваивает спортшкола или орган власти по протоколу старта нужного ранга, и интерфейс показывает оба слоя.

## Источник чисел

Приложение № 1 к приказу Минспорта России от 06.11.2024 № 1092, [номер опубликования 0001202411150002](http://publication.pravo.gov.ru/document/0001202411150002). Сторонние сайты в датасет не попадают.

Датасет, это статические TS-модули, версионированные по редакциям: [`editions/2024-11-26`](src/domain/standards/editions/2024-11-26). 35 событий, 70 строк, оба бассейна, эстафеты не входят. Времена переписаны так, как их печатает приказ, `m:ss.hh`, чтобы строку можно было сверить со сканом не пересчитывая её в голове.

Контрактный тест держит форму датасета: ключ `pool|sex|stroke|distance` уникален, времена строго убывают по ступеням от медленной к быстрой, прочерк приказа выражен отсутствием ключа, а не нулём, покрыто ожидаемое множество событий для обоих бассейнов и обоих полов. Опечатка в переписанной таблице падает там, а не у пользователя.

## Адреса

| Адрес | Что там |
|---|---|
| `/` | приложение, режим нормативов |
| `/?mode=calculator` | приложение, режим калькулятора |
| `/normativy/` | указатель всех событий |
| `/normativy/{бассейн}/{стиль}/{дистанция}/` | справочная страница одного события |
| `/razryady/` | что такое разряд, ЕВСК и что меняет бассейн |
| `/qr/` | QR-визитка приложения |
| `/kitchen-sink/` | рендер всех примитивов |

Справочный слой пререндерится целиком и существует ради поиска: 35 страниц, по одной на событие. `sitemap.xml` и `robots.txt` собираются из того же перечня комбинаций, что и сами страницы.

## Стек

Серверного рантайма нет. Нормативы, это неизменяемый датасет в репозитории, а весь расчёт помещается в браузер, поэтому всё, что ломает `output: 'export'`, запрещено: серверные экшены, роут-хендлеры, ISR, middleware, оптимизатор изображений, динамический роут без `generateStaticParams`.

| Слой | Выбор |
|---|---|
| Язык | TypeScript 5, `strict` |
| Фреймворк | Next.js 15, App Router, `output: 'export'` |
| Пакетный менеджер | pnpm |
| Данные | статические TS-модули, версионированные по редакциям ЕВСК |
| Валидация датасета | Zod, только в тестах |
| Стили | CSS Modules плюс глобальные CSS-переменные ролей |
| Тесты | Vitest, fast-check |
| Линт | ESLint, Prettier |
| CI | GitHub Actions |
| Хостинг | Timeweb Cloud, статика из каталога `out/` |

Ликов два, тёмный ОБСИДИАН и светлый ТИТАН. Переключение меняет только CSS-переменные и запоминается до следующего визита. Цветовых значений вне `globals.css` не существует, в модулях только `var(--role)`. Любое число рендерится моноширинным шрифтом с `font-variant-numeric: tabular-nums`.

## Запуск

```bash
pnpm install
pnpm dev
```

| Команда | Что делает |
|---|---|
| `pnpm dev` | дев-сервер Next.js |
| `pnpm build` | статический экспорт в `out/` |
| `pnpm lint` | ESLint, ноль предупреждений |
| `pnpm typecheck` | `next typegen` и `tsc --noEmit` |
| `pnpm test` | Vitest, один прогон |
| `pnpm test:watch` | Vitest в watch |
| `pnpm format` | Prettier |

Посмотреть саму сборку, вместе с офлайном и установкой на домашний экран:

```bash
pnpm build && python3 -m http.server 4173 --directory out
```

## Структура

```
src/
  app/        роуты, тонкие: собирают данные и рендерят компонент фичи
  domain/     чистая логика: шкала очков, парсинг времени, датасет и доступ к нему
  features/   представление фич, от калькулятора до установки и шеринга
  ui/         примитивы, не знают о предметной области
  lib/        адреса, подписи, метаданные, тема, аналитика
public/       манифест, иконки, сервис-воркер, стартовые экраны iOS
```

Компонент в `ui/` не импортирует из `domain/` и `features/`. `any` запрещён, включая `as any`. Время внутри домена всегда число секунд, строка `mm:ss.hh` живёт только на границе ввода и вывода. Пользовательские строки русские, имена в коде, комментарии и коммиты английские.

## Проверка перед PR

Слайс закрыт, когда зелены все шесть пунктов Definition of Done из `tech.md`. Четыре из них проверяет CI на каждом PR:

```bash
pnpm lint && pnpm typecheck && pnpm test && pnpm build
```

Оставшиеся два проверяются глазами: новые страницы лежат в `out/` готовыми `index.html`, и экраны приложения держат высоту окна без скролла в обоих ликах на диапазоне высот, а не на двух контрольных точках.

## Документация

`tech.md`, единственный источник истины: схема данных, общие типы, контракты, конвенции кода, задачи и changelog ядра. Расхождение кода с ним решается в пользу `tech.md`.

`CLAUDE.md`, правила работы поверх него для агента.

## Деплой

Timeweb Cloud собирает приложение на своём раннере и раздаёт `out/`, потому что каталог сборки в `.gitignore`. Ветка `release-main` несёт то же дерево, что и `main`, одной сжатой историей, и уходит в `origin/main`.
